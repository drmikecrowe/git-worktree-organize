## Git Config Isolation Approaches

Tests must NOT use user's ~/.gitconfig. Options (planner's discretion):

**Option A: Environment Variable (Recommended)**
```typescript
// In makeTempDir or repo factory functions:
import { spawn } from 'node:child_process'

// Set GIT_CONFIG_GLOBAL to /dev/null or temp file
const env = { ...process.env, GIT_CONFIG_GLOBAL: '/dev/null' }
await run('git', ['init', dir], { quiet: true, env })
```

**Option B: Inline Config Flags**
```typescript
// Pass -c user.email and -c user.name with every git command
await run('git', ['-c', 'user.email=test@test.com', '-c', 'user.name=Test', 'init', dir], { quiet: true })
```

**Option C: Temp HOME Directory**
```typescript
// Set HOME to temp dir for each test
const env = { ...process.env, HOME: tempHomeDir }
```

Recommendation: Option A (GIT_CONFIG_GLOBAL) is cleanest - set it once per repo creation.
