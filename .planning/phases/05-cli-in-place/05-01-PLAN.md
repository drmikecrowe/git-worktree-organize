<task id="2" type="code">
<title>Implement validation mode in CLI</title>

In `src/cli.ts`, add routing after `detect()` call:

1. Check if `config.type === 'bare-hub'`
2. If true, call `runValidationMode()` and exit
3. Implement `runValidationMode()`:
   - Call `listWorktrees()` to get all worktrees
   - For each worktree, determine status:
     - **healthy**: path exists AND .git pointer valid
     - **missing**: path does not exist
     - **stale**: path exists but .git points to wrong location
   - Print table: Branch | Path | Status
   - Print summary: "X healthy, Y missing, Z stale"

**Verify:** `npm test test/cli.test.ts` passes
</task>
